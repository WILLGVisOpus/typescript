# Task 2.2 — `visopus-mfa` metadata helpers (Issue #206 / Phase 2)

**Date:** 2026-04-29
**Branch:** `feat/206-zitadel-soft-mfa-fork`
**Issue:** [#206 — Soft-required MFA umbrella](https://github.com/WILLGVisOpus/VisOpus-Test/issues/206)
**Plan:** Task 2.2

## Goal

Two pure helpers for the `setMfaSatisfiedViaRecoveryCode` flow: turn the
literal string `"recovery_code"` into the `Uint8Array` payload that
Zitadel session metadata expects, and decode it back when reading.
The agreed key `visopus_mfa_satisfied_via` is the contract between
the recovery-code challenge page (Phase 3, Task 3.4) and the soft-gate
decision (Task 2.4).

## What landed

### `src/lib/server/visopus-mfa.ts`

```ts
export const SATISFIED_VIA_KEY = "visopus_mfa_satisfied_via";
export type SatisfiedVia = "recovery_code";
export function encodeSatisfiedVia(value: SatisfiedVia | string): Uint8Array;
export function decodeSatisfiedVia(metadata: Record<string, Uint8Array> | undefined): string | null;
```

`decodeSatisfiedVia` returns `null` for: missing metadata bag, missing
key, and zero-length values. That last case is mild paranoia — Zitadel
shouldn't return empty values in metadata, but a zero-length entry would
otherwise decode to the empty string and look like a satisfied-via
marker to a careless caller.

The file does NOT use `"use server"`. The plan suggested it, but these
are sync utility functions; a `"use server"` directive forbids non-async
exports and would break the build. They're safe to import from both
server and client paths.

### `src/lib/server/visopus-mfa.test.ts`

Seven vitest cases:

- `SATISFIED_VIA_KEY` matches the agreed string.
- `encodeSatisfiedVia` returns the right UTF-8 bytes.
- Round-trip `recovery_code`.
- Returns `null` when key absent.
- Returns `null` when metadata bag undefined.
- Returns `null` when value is empty (defensive).
- Ignores other keys.

## Plan deviation

- Dropped the plan's `"use server"` directive — these are pure helpers
  with sync exports.
- Added `SatisfiedVia` type alias so future callers get auto-complete
  on the marker value.
- Defensive zero-length-value branch in `decodeSatisfiedVia`.
